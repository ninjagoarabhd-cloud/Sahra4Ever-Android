# Sahra4Ever Android (WebView wrapper)

Loads https://sahra4ever.vercel.app inside a WebView. The website itself is not modified.
Build: GitHub > Actions > "Build Sahra4Ever APK" > Run workflow > download artifact "Sahra4Ever-APK".

Change the site URL / allowed hosts: app/src/main/java/com/sahra4ever/app/MainActivity.java
Change icon colour: app/src/main/res/values/colors.xml
